# משימה: תיאור מושגי לקטעים מספר השיחות (לשיפור חיפוש סמנטי)

קובץ הקלט הוא מערך JSON של קטעים מתוך שיחות של כ"ק אדמו"ר הריי"צ (לקוטי דיבורים חלק ג, בתרגום עברי של קה"ת). לכל קטע: i (מספר), t (שם השיחה), x (הטקסט).

לכל קטע כתוב תיאור קצר בעברית (25–60 מילים) שיעזור למנוע חיפוש למצוא את הקטע לפי שאלות של לומדים. התיאור צריך לכלול:
1. **הנושאים והמושגים** שהקטע עוסק בהם — גם מושגים מופשטים שהקטע מבטא בלי לנקוב בשמם. לדוגמה: קטע שאומר "חסידים הולכים לאט־לאט, צעד אחר צעד" עוסק ב"מתינות, הדרגתיות"; קטע על "בלי חיפזון" — "מתינות, יישוב הדעת"; קטע על נגינה בתפילה — "ניגון, תפילה, התעוררות הנפש". השתמש במונחים החסידיים המקובלים (ביטול, אהבת ישראל, התבוננות, עבודת התפילה, חינוך, התקשרות, מסירות נפש, יישוב הדעת, שמחה, קבלת עול, פנימיות וכו') כשהם באמת מתאימים.
2. **אנשים** שמוזכרים בתפקיד משמעותי (למשל: אדמו"ר הזקן, הצמח צדק, אדמו"ר מהר"ש, אדנ"ע/כ"ק אאמו"ר, ר' פלוני החסיד).
3. **סיפורים/מעשים** — במשפט קצר מה קרה (למשל: "סיפור על ילד שרקד ובכה בשמחת תורה").
4. **הוראות מעשיות** אם יש.

כללים:
- כתוב רק מה שיש בקטע באמת. אל תמציא ואל תוסיף מידע חיצוני.
- אל תעתיק משפטים שלמים מהטקסט — תאר במילים שלך, בשפה שבה אדם היה שואל.
- אם הקטע קצר מאוד או רק כותרת/מעבר — תיאור קצר מתאים (אפילו 5–10 מילים).
- סגנון: רשימת מושגים ואחריה משפט או שניים. בלי הקדמות כמו "הקטע עוסק ב...".

פלט: כתוב קובץ JSON בנתיב שנמסר לך — מערך של {"i": <מספר>, "d": "<תיאור>"} לכל הקטעים בקובץ הקלט, באותו סדר, בלי לדלג על אף אחד. ודא שהקובץ תקין (טען אותו עם python json.load ובדוק שמספר הפריטים שווה למספר הקטעים בקלט). בסיום החזר רק שורה אחת: מספר הפריטים שנכתבו.

הערה: הטקסט עבר זיהוי תווים (OCR) ועלולות להיות בו טעויות אותיות קטנות — התעלם מהן. בלקוטי דיבורים הדובר הוא אדמו"ר הריי"צ; "אבי"/"כ"ק אאמו"ר" = אדמו"ר הרש"ב; "רבנו הגדול"/"רבנו הזקן" = אדמו"ר הזקן; "הרבי" בסיפורים = לפי ההקשר — ציין את השם המפורש בתיאור כשהוא ברור.
